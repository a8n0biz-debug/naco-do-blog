# naco-do コラム制作スキル

## ブランド基本情報

**サービス名**: naco-do（ナコード）  
**運営会社**: 株式会社いろもの  
**公式サイト**: https://naco-do.com/  
**サービス定義**: 「結婚相談所ではなく、パーソナル婚活コーチング」（公式メタ説明より）。アプリでも相談所でもない、新しい婚活の選択肢  
**コンセプト**: 「抱え込まないで、いい婚活。シン・婚活」  
**ターゲット**: 婚活中の女性（主に20〜30代）・男性（30〜40代）

### パーソナル婚活診断

無料オンライン面談内で実施するオリジナル診断。あなたの婚活状況から「うまくいかない原因」と「理想の結婚生活」を明確にし、あなたに合う婚活の進め方を一緒に設計する。

**紹介時の注意事項**
- Webツール・自動診断・60秒診断ではなく、**面談の中でプランナーと一緒に行うもの**
- 必ず「無料面談で受けられる」という文脈で紹介すること
- 「60秒ほどで〜」「オンラインツールで〜」などの表現は使わない

### ブランドトーン

- **温かく・共感的**：読者の気持ちに寄り添い、「わかってもらえた」と感じさせる
- **前向き・具体的**：漠然とした励ましではなく、課題→解決の流れで納得感を出す
- **押しつけない**：「こうすべき」ではなく「あなたはどうしたい？」の姿勢を反映
- **等身大**：華美・大げさにならず、リアルな婚活者の感覚に近い言葉を選ぶ

## タスク別ガイドライン

### 1. ブログ記事の新規作成・リライト

**構成の基本パターン**

- **タイトル直下の冒頭文**：以下の2点を必ず盛り込む
  1. 共感できる問いかけや読者の悩みの提示
  2. 結論ファーストの構成にし、見出し直下に内容の要約を記載する
- **H2セクションの冒頭**：必要に応じてタイトルの問い・テーマを受けた共感フレーズまたは読者の悩みの提示
- **H3セクション**：H2のボリューム・内容に応じて作成
- **本文**：課題提示 → 一般論 → naco-doの解決策 → 具体的ベネフィット
- **締め**：行動喚起または温かい応援メッセージ

**⚠️ CTA設定（必ず適用・省略・変更禁止）**

記事本文中の**KWに最も関連する段落の直後**と、**naco-do紹介の直後**の2箇所に挿入する。

【中間CTA】KWに最も関連する段落の直後に挿入
```
naco-do（ナコード）の無料面談では、あなたの婚活状況をもとに
「うまくいかない原因」と「理想の結婚生活」を明確にして、
あなたに合う婚活の進め方を一緒に設計する
「パーソナル婚活診断」を無料で受けられます。
話を聞くだけ、診断を受けるだけでもOKです。
```

【末尾CTA】naco-do紹介の直後に必ず挿入（記事トーンに合わせた微調整は可。内容・要素は省略しないこと）
```
パーソナル婚活 naco-do（ナコード）の無料面談では、あなたの婚活状況から「うまくいかない原因」や「理想の結婚生活」を明確にし、あなたに合う婚活の進め方まで一緒に設計する「パーソナル婚活診断」を無料で受けられます。
婚活の課題がクリアになるので、今後の婚活に生かせるヒントが詰まっています。
話を聞くだけ、診断を受けるだけでもOK。まずは気軽にのぞいてみてください。
```

**内容に関するルール**
1. **一次情報を引用し、引用元のURLを記載する**（統計・調査・専門知識を使う際は必ず出典明記）
2. **他社に関わる記事では公式サイトから得られる情報のみ記載する**（口コミ・第三者評価サイトの内容は使わない）
3. **ナコード総研の記事を自然な形で引用する**（婚活に関する調査データは積極的に活用し、記事の信頼性を高める）
4. **KWに関連する「よくある質問（FAQ）」の段落を作成する**（H2またはH3として記事末尾付近に配置。Q＆A形式で3〜5問を目安）

**段落生成・融合の手順**
1. 既存段落の主旨と論点を確認する
2. 追加・融合する要点を自然な流れで組み込む
3. naco-doへの言及は過剰にならないよう1〜2箇所に絞る
4. ボリューム感のバランス（追加前後で極端に変わらない）を保つ

**文体ルール**
- 体言止め・短文・問いかけを効果的に使いリズムを出す
- 「——」（ダッシュ）は感情的な余韻・補足に有効
- **太字**は段落内で最重要な1フレーズのみに絞る
- 段落末の締め文はポジティブ・前向きに

### 2. 成婚インタビュー記事（コラムタイトル＋サポーターコメント）

インタビュー回答を受け取ったら、以下を生成する。

#### タイトルのルール
- インタビュー内で最も印象的なキーワード・エピソードを核にする
- 「等身大」「自分らしさ」「自己理解」などnaco-do体験の本質を反映する
- ターゲット読者が「自分ごと」として読めるよう、共感ワードを盛り込む
- 形式例：「〇〇──△△が、成婚への○○をつくった」「〇〇だった私が、△△できた理由」

#### サポーターコメントのルール
- **文字数**: 200〜250文字厳守
- **視点**: 担当サポーターとして、会員の成長・変化を温かく振り返る
- **構成**: ①回顧（婚活中のエピソードに触れる）→ ②称賛（本人の努力・姿勢）→ ③祝福・エール
- **禁止**: 「頑張って下さい！」のような定型的な締めは避け、個別性を出す
- サポーターの名前が回答に含まれる場合は自然に盛り込む

### 3. note記事の作成・編集

#### noteプロフィール（自己紹介文）

**基本ルール**
- **文字数**: 140文字以内厳守
- 「マッチングアプリでも結婚相談所でもない」という否定形の定義づけを軸に、naco-doの独自ポジションを一文で伝える
- 締めは「一緒に叶えます」など**伴走感・温かさ**が出る表現で終わる
- AIマッチングへの言及は不要

**確定フォーマット（過去実績より）**
> ひとり一人の価値観とライフスタイルを大切に、「あなたはどうしたい？」から始まる婚活を。naco-do（ナコード）は、マッチングアプリでも結婚相談所でもない新たな婚活の選択肢。あなたの想いに寄り添いながら、10年後もその先も長く幸せが続く結婚生活を一緒に叶えます。（123文字）

**含めるべき要素**

| 要素 | フレーズ例 |
|---|---|
| サービス定義 | 「マッチングアプリでも結婚相談所でもない新たな婚活の選択肢」 |
| 寄り添い姿勢 | 「ひとり一人の価値観とライフスタイルを大切に」「あなたはどうしたい？」 |
| ゴール | 「10年後もその先も長く幸せが続く結婚生活」 |
| 伴走感 | 「一緒に叶えます」「寄り添いながら」 |

#### note記事本文

**基本的な構成ルール**
- ブログ記事の構成パターン（タイトル直下の冒頭文・H2・H3）に準じる
- **文字数は5000文字以上**を目安に、情報量・読み応えのある記事にする
- noteは縦読みされやすいため、**段落は短め（3〜4行）**に区切る
- 見出しは読者が「自分ごと」として読める問いかけ形式が効果的
- **ナコード総研の調査データを積極的に活用し**、記事の信頼性・説得力を高める（引用元URLを明記）
- **H2ごとに最重要なフレーズを1箇所太字**にする
- 記事末尾に**naco-doへの誘導文**を自然な流れで入れる（以下のCTAテンプレートを使用すること）

- ブログより**会話調・柔らかめ**のトーンでも可

- 読者への問いかけ（「〜ありませんか？」「〜感じていませんか？」）をリズムよく挿入

### 5. 添削

以下の観点でチェックする。

**明確な誤り（必ず指摘）**
- 誤記号（ダッシュ「―」の混入など）
- 助詞の抜け・誤用
- 誤字・脱字

**表記の統一**
- 名前の前後スペースの統一
- 同一語の表記ゆれ（「サポーター」「サポ―ト」等）
- 句読点の統一

**文体・表現**
- 同一語の同一段落内での重複（「各々」等）→ 「お互い」などに言い換え提案
- 冗長な表現 → 簡潔な代案を提示
- 締め文の前向きさ・温かさの確認

## 禁止・注意事項

- AIマッチング機能への言及は不要（現在のサービス訴求から外れている）
- 「こうすべき」「〇〇しなければ」など命令・脅迫トーンは使わない
- 成婚率・費用など数値は公式サイト（https://naco-do.com/）で最新値を確認してから使用する
- 他社サービスへの言及は公式サイト情報のみとし、口コミや比較サイトの評価は使わない
- 会員の個人情報（フルネーム等）は仮名・ニックネームで扱う
