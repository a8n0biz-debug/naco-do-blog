## 主要知見④：A群の「限界・やめたい層」は言語化度合いが低い

### A群「現在の婚活への気持ち」（Q5・n=500）
1位 続けてはいるが、少し疲れている（49.2%）
2位 前向きに取り組めている（25.2%）
3位 かなり疲れていて、やめたいと思うことがある（17.0%）
4位 限界を感じている（8.6%）
- 限界・やめたい層＝17.0+8.6＝**25.6%（n=128）**＝約4人に1人
- 続けられている層＝25.2+49.2＝**74.4%（n=372）**
- 何らかの疲労感（前向き以外）＝49.2+17.0+8.6＝**74.8%**

### 「限界・やめたい層」と「続けられている層」の実践自覚率比較（続：n=372／限：n=128）
1位 大事にしている価値観を自分の言葉で説明できる（続 79.8% / 限 61.7% / +18.1pt）
2位 結婚相手に求めることを言語化できる（続 76.6% / 限 45.3% / +31.3pt）
3位 パートナーとの関係性を明確にイメージできる（続 76.1% / 限 50.8% / +25.3pt）

- 6項目すべてで続層が18pt以上上回る。最大乖離：結婚相手の言語化+31.3pt、つまずき把握+27.1pt。

## 完全版（第1部＋第2部マージ）の論理ライン

1. 婚活は心身に負担を伴う（A群約8割・B群約7割が負荷経験／A群46.6%受診経験）
2. 続ける/やめるを分けるのは外的要因だけでなく自己理解の程度
3. A群×B群、続層×限層ともに価値観・結婚像・関係性の言語化度合いに差（+2.80点／2.91点）
4. **心身の限界に達しにくいのは、価値観を起点にした婚活ができている人**
5. これからの婚活サービスには相手探しと「自分の内面を知り、整理する支援」が同水準で求められる
