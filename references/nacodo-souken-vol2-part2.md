## 独自用語・指標の定義

**幸福実感率**：「とても幸せを感じている」または「やや幸せを感じている」と回答した人の合計割合

**パーソナル婚活スコア**：自己理解6項目（4段階／24点満点）を合算した独自指標
- 高群：19〜24点（n=181）
- 中群：12〜18点（n=551）
- 低群：6〜11点（n=68）

**すり合わせ9テーマ**：結婚後に価値観のすり合わせが必要になりやすい9つのテーマ
1. 住まい・生活リズム
2. 家事の分担
3. お金の使い方・貯金
4. 子どもについての考え
5. 親・家族との関わり方
6. 仕事・キャリア
7. 趣味
8. お互いの気持ちや愛情の伝え方
9. 困ったときの向き合い方

**価値観9領域**：すり合わせ9テーマと同じ9領域について、現在「価値観が合っているか」を測るもの

## 主要知見③｜交際中に話し合えたテーマが多い人ほど幸福度が高かった

### すり合わせ9テーマの話し合い率（n=800）

| テーマ | 話し合い率 |
|---|---|
| 住まい・生活リズム | 72.5% |
| 親・家族との関わり方 | 70.5% |
| 子どもについての考え | 67.4% |
| 趣味の過ごし方 | 66.7% |
| 仕事・キャリアの考え方 | 64.4% |
| お互いの気持ちや愛情の伝え方 | 63.4% |
| お金の使い方・貯金 | 63.2% |
| 困ったときの支え合い方・意見が違ったときの向き合い方 | 58.5% |
| 家事の分担 | 57.9% |

→ 意見の違いが表面化しやすいテーマほど話し合われにくい傾向

### 話し合えたテーマ数別 幸福実感率（n=800・全体82.9%）

| 話し合い数 | 幸福実感率 |
|---|---|
| 0個（n=64） | 50.0% |
| 1〜2個（n=83） | 57.8% |
| 3〜4個（n=112） | 79.5% |
| 5〜7個（n=213） | 82.2% |
| 8〜9個（n=328） | **97.3%** |

→ **0個と8〜9個の差：47.3pt**
→ 2個以下は5割台、3個以上は8割前後に達する

### 話し合えたテーマ数別「結婚の決め手」比較

| 決め手 | A群（8〜9個 n=328） | B群（0個 n=64） | 差 |
|---|---|---|---|
| 趣味・好みが合う | 31.1% | 4.7% | +26.4pt |
| 価値観が近い | 36.3% | 14.1% | +22.2pt |
| 意見が違っても話し合える | 15.5% | 4.7% | +10.8pt |
| 自分の考えを話しやすい | 13.4% | 7.8% | +5.6pt |
| 困ったときに支え合える | 16.2% | 39.1% | −22.9pt |

→ 話し合えた数が多い人は「価値観・趣味」を決め手に、少ない人は「感情的安心感」を決め手にする傾向

### パーソナル婚活スコア別の交際中話し合いテーマ数平均

| 群 | 平均話し合いテーマ数 |
|---|---|
| 高群（19〜24点） | 7.8個 |
| 低群（6〜11点） | 2.4個 |

→ 自己理解の深さが対話の幅と連動

## 総括データ

**自己理解→対話→価値観の合致→幸福という一連の流れ**

- パーソナル婚活スコア高群：交際中の話し合いテーマ数平均7.8個
- パーソナル婚活スコア低群：交際中の話し合いテーマ数平均2.4個
- 話し合いテーマ8〜9個：幸福実感率97.3%
- 話し合いテーマ0個：幸福実感率50.0%
- 価値観合致9領域：幸福実感率98.9%
- 価値観合致0〜3領域：幸福実感率31.6%
