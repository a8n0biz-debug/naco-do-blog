## 独自用語・指標の定義

**幸福実感率**：「とても幸せを感じている」または「やや幸せを感じている」と回答した人の合計割合（全体82.9%）

**幸せを感じている群**：「とても幸せ」＋「やや幸せ」と回答した人（n=663）

**幸せを感じていない群**：「あまり幸せを感じていない」＋「まったく幸せを感じていない」と回答した人（n=137）

**すり合わせ9テーマ**：住まい・生活リズム／家事の分担／お金の使い方・貯金／子どもについての考え／親・家族との関わり方／仕事・キャリア／趣味／お互いの気持ちや愛情の伝え方／困ったときの向き合い方

## 主要知見⑥｜幸せな人は「話しにくいテーマ」も話せていた

### テーマ別 話し合い率比較（幸せ群 vs 感じていない群）

| テーマ | 幸せ群 | 感じていない群 | 差 |
|---|---|---|---|
| お金の使い方・貯金 | 70.1% | 29.2% | **+40.9pt** |
| お互いの気持ちや愛情の伝え方 | 70.1% | 30.7% | **+39.4pt** |
| 親・家族との関わり方 | 77.1% | 38.7% | +38.4pt |
| 仕事・キャリアの考え方 | 70.3% | 35.8% | +34.5pt |
| 家事の分担 | 63.7% | 29.9% | +33.8pt |
| 困ったときの支え合い方・意見が違ったときの向き合い方 | 64.1% | 31.4% | +32.7pt |
| 趣味の過ごし方 | 72.1% | 40.1% | +32.0pt |
| 住まい・生活リズム | 78.0% | 46.0% | +32.0pt |
| 子どもについての考え | 72.5% | 42.3% | +30.2pt |

→ **幸せ群は9テーマすべてで6割超**
→ **感じていない群は全テーマで5割未満**
→ 差はすべてのテーマで+30pt以上

### 「もっと話し合っておけばよかった」テーマ（n=800・複数回答）

| 順位 | テーマ | 割合 |

## 主要知見⑦｜話し合えた人のほうが現在の価値観合致率が高かった

### テーマ別 話し合えた群 vs 話し合えなかった群の現在の価値観合致率

| テーマ | 話し合えた群 | 話し合えなかった群 | 差 |
|---|---|---|---|
| お金の使い方・貯金 | 87.5% | 50.2% | **+37.3pt** |
| 住まい・生活リズム | 89.0% | 53.6% | +35.4pt |
| 趣味の過ごし方 | 87.8% | 55.1% | +32.7pt |
| 親・家族との関わり方 | 84.6% | 53.0% | +31.6pt |
| 子どもについての考え | 86.3% | 55.2% | +31.1pt |
| お互いの気持ちや愛情の伝え方 | 87.6% | 59.4% | +28.2pt |
| 家事の分担 | 85.5% | 59.1% | +26.4pt |
| 困ったときの支え合い方・意見が違ったときの向き合い方 | 86.5% | 61.1% | +25.4pt |
| 仕事・キャリアの考え方 | 86.6% | 64.2% | +22.4pt |

→ **9テーマすべてで話し合えた群の合致率が高い（差+22.4〜+37.3pt）**
→ 後悔1位の「お金」は話し合いによる合致率の差も最大（+37.3pt）

## 主要知見⑧｜違和感を言葉にできた人は幸福実感率が9割超

### 交際中の「違和感への対処」別 現在の幸福実感率

| 対処の仕方 | n | 幸福実感率 |
|---|---|---|
| 自分の中で整理したうえで必要に応じて相手に伝えていた | n=271 | **92.6%** |
| 違和感や不安を言葉にして相手と話し合っていた | n=115 | **92.2%** |
| 特に違和感や不安はなかった | n=146 | 91.1% |
| 違和感はあったが相手にはあまり伝えなかった | n=122 | 68.9% |
| 覚えていない | n=93 | 63.4% |
| 違和感はあったが見ないようにしていた | n=53 | 56.6% |
| **全体** | **n=800** | **82.9%** |

→ **違和感を言葉にして伝えた人：92%超**
→ **違和感を伝えなかった・見ないようにした人：57〜69%**
→ 重要なのは伝え方のスタイルではなく「言葉にすること」

## 総括データ（Vol.2シリーズ）

- 現在の配偶者との結婚を「選んでよかった」と考える人：**81.8%**
- 交際中に優先して話し合うべきテーマ（後悔上位×合致率差が大きい）：**お金・子ども・困ったときの向き合い方**
- 幸せな結婚生活に共通する力：自己理解→対話（言葉にする）→違和感の言語化
