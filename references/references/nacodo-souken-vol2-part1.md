## 独自用語・指標の定義

**幸福実感率**：現在の結婚生活への幸福感について「とても幸せを感じている」または「やや幸せを感じている」と回答した人の合計割合

**パーソナル婚活スコア**：自己理解6項目（4段階／24点満点）を合算した独自指標
- 高群：19〜24点（n=181）
- 中群：12〜18点（n=551）
- 低群：6〜11点（n=68）

**自己理解6項目**（結婚を意識し始めた頃にできていたかを4段階で回答）：
1. パートナーとどんな関係性を築きたいかイメージできた
2. 自分が大事にしている価値観を言葉で説明できた
3. 結婚後にどんな日常を送りたいか具体的にイメージできた
4. 自分が結婚相手に求めることを言語化できた
5. 自分が婚活でつまずいていた原因や課題を把握していた
6. 自分の強みや魅力を自分の言葉で人に伝えられた

## 主要知見①｜幸福実感率は属性では分かれなかった

### 現在の結婚生活への幸福実感率（n=800）

| 幸福感 | 割合 |
|---|---|
| とても幸せを感じている | 40.4% |
| やや幸せを感じている | 42.5% |
| あまり幸せを感じていない | 10.3% |
| まったく幸せを感じていない | 6.9% |

- **幸福実感率（上位2つの合計）：82.9%**
- 「とても幸せ」は4割強にとどまり、幸福感の深さには幅がある

### 性別・年代別 幸福実感率（n=800）

| グループ | 幸福実感率 |
|---|---|
| 女性20代（n=41） | 87.8% |
| 女性30代（n=252） | 86.9% |
| 男性30代（n=167） | 85.0% |
| 男性40代（n=176） | 81.8% |
| 女性40代（n=145） | 74.5% |
| 男性20代（n=19） | 73.7% |
| **全体平均** | **82.9%** |

→ 最高（女性20代87.8%）と最低（男性20代73.7%）の差は14.1pt
→ 性別・年代・職業・世帯年収・子供の有無では幸福度に体系的な大差なし
